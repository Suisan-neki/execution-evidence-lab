# 理解とテストの入口

2026-10-07に本人が指定した二つの機能を扱う。理解機能では公開GitHubのコードを読み取り、構成・入口・関数・参照先をたどる。テスト機能では対象の処理を実行して期待する動作・失敗・未確認事項を確かめる。両機能の間でコードと結果を対応づける。

## 現在の起動方法

PR #110・#126・#130はmainへマージ済み。

```bash
git switch main
git pull --ff-only
cargo run -- explore
```

表示されたURLを開く。理解だけを使う場合は事例の初期化が不要。GitHubの読取は利用者のブラウザから公開APIとraw.githubusercontent.comへ行う。トークンや非公開リポジトリには対応していない。

理解とテストの記録を同じ画面から使う場合は以下で起動する。

```bash
# 未作成の事例を始めるときだけ実行する。
cargo run -- case init cases/pr110-review
cargo run -- review cases/pr110-review
```

`/`が理解画面。`/review`がテストと判断の記録。事例を作成済みなら初期化は省く。既存の試験や判断は書き換えない。

## 理解画面でできること

1. 公開リポジトリのURLを入力する。任意でブランチ・タグ・コミットを指定する。
2. コミットを固定してファイル構成を取得する。README・設定・コードの最大24ファイルを初回に読む。
3. 作者の説明と読む入口を確認する。説明から同じコミットのGitHubへ戻れる。
4. ファイルを選び、関数宣言と参照先をたどる。行番号付きコードと参照宣言の出所を確認する。
5. 初回に読まなかったファイルは選択時に追加で読む。サイズ上限は1ファイル128KiB。
6. 読取記録をJSONで保存し、同じ画面で開ける。保存記録を開いたことと現在のGitHubとの照合を区別する。

READMEやコメントは作者による説明。入口の候補と簡易解析した参照宣言はコードを読む補助であり、実行順序や実際に通った経路の証明ではない。

## 理解からテストへ

事例を開いている場合は「このコードから確認事項を作る」を使う。固定したコミット・ファイル・行のURLを条件の出所へ渡す。利用者が確かめたい動作を記入する。追加した条件は判定方法未定義なのでUnknownのまま始める。

条件の出所から同じコードへ戻れる。GitHubからコードを読んだだけで任意のアプリを起動することはない。保存デモのほか、起動時に対象を指定した画面では固定版のNode.js／Pythonコードを実行できる。外部アプリには実行設定・観測方法・判定規則が必要。[実行手順](pinned-execution.md)を参照する。

## 解析の範囲

Rust、JavaScript / TypeScript、Pythonの関数宣言の一部を抽出する。JSの相対import、Rustのmodと一部のuse、Pythonの相対fromを既知のファイルへ解決する。複雑な構文、動的import、呼び出しの完全な解析、依存パッケージ内部の解析には対応しない。

コメントや文字列内の関数名を宣言として数えない確認がある。Rustのraw文字列・入れ子のブロックコメント、Pythonの複数行文字列とJavaScriptの一部の正規表現は除外する。テンプレート文字列内の式は解析しない。構文解析器と同じ網羅性はない。解決できなかった参照を「参照がない」と表示しない。未読・取得失敗・一覧の途中切れを表示する。

AIによる業務上の意味の説明・質問への応答は未実装。今回の簡易解析だけで理解機能全体が完成したとは扱わない。任意の公開アプリの自動テスト、非公開GitHubの認証、実環境・実参加者での確認も残る。

## 読むコードと確認方法

- `ui/scanner.js`：公開URL、版の固定、範囲を限定した読取、宣言・参照の抽出。
- `ui/explorer.js`：説明とコードの行の表示、参照先への移動、読取記録、確認事項への引継ぎ。
- `src/review.rs`：理解とテストの二画面をlocalhostで配信する。
- `tools/scanner-tests.mjs`：コメント・文字列・Rustのライフタイム、版固定、相対参照、URLと上限、API制限。
- `tools/explorer-smoke.mjs`：固定したGitHub応答を使うブラウザ操作と出所の引継ぎ。実参加者の理解評価ではない。

GitHubのTree APIの仕様は[公式資料](https://docs.github.com/en/rest/git/trees)を参照した。公開コードは認証なしで取得できる。一覧がtruncatedの場合は全体を取得したとは扱わない。

## コードへ戻り、更新後の版を確認する

2026-10-13の追加実装。条件には任意の`source`としてリポジトリ・固定コミット・相対パス・行範囲を残す。試行の取り込み時にも、その時点の参照を複製する。旧記録にこの項目がなくても読込できる。固定コードURLが出所にある旧条件からも理解画面へ戻れる。

1. テスト画面の「理解画面でコードを読む」から、参照していた版と行へ戻る。直前の読取記録が同じタブにあれば使い、なければ固定コミットをGitHubから読む。
2. 関数を選ぶと宣言・入力や型・分岐・繰り返し・非同期の待機・戻りとエラーの記述を表示する。呼び出しは同名の宣言と参照先から候補を示す。コードの記述順を実行順序として扱わない。
3. 「別の版と比較する」にブランチ・タグ・コミットを指定する。Git blobの識別値、読取本文、ファイル種別を比較し、変更・追加・削除・同じ・分からないを分ける。一覧が不完全な側では追加・削除を断定しない。
4. 比較した版のファイルを開き、対応する関数・行を選ぶ。行番号が変更前と同じ意味を持つとは推定しない。記入者と理由を入力して、その条件の参照先を更新する。
5. 古い試行・判断当時の根拠は残る。条件版と参照コードが変わるので現在の判定は再確認待ちになる。同じ本文でも参照コミットが変わった場合は保守的に再確認する。

この`source`は利用者が対応づけた確認事項の参照先であり、試行がそのコードを実行したという証明ではない。固定版Node.js／Pythonの実行設定・観測・照合は[pinned-execution.md](pinned-execution.md)を参照する。任意アプリの自動計測や他の実行環境との照合は未実装。既存の保存デモを再試験したことから、GitHubで選んだアプリの成功を主張しない。

本文の比較は前後で一致する先頭・末尾を除いた範囲を示す。最小の行差分や意味差分ではない。一覧は200件、本文の異なる範囲は各120行、関数内の案内は種類ごと80件まで表示する。未読本文は差分表示へ補わない。保存した読取記録とGitHubの一致・真正性は保証しない。

読む順番は`ui/comprehension.js`（読解案内・比較・参照）、`ui/explorer.js`（版比較と復帰）、`src/workspace.rs`（条件と根拠の参照・更新）、`ui/review.js`（現在と過去の参照表示）。追加検証は`tools/comprehension-tests.mjs`・`tests/workspace.rs`・`tools/explorer-smoke.mjs`。

## 読み込みの別名と呼び出し元を読む（#129）

関数を選ぶと、「呼び出し先の候補をたどる」と「この関数を呼ぶ候補」を表示する。呼び出しの行、対応する読み込み宣言、候補の関数宣言を開ける。呼び出し元の候補から元のファイルと行へ戻れる。参照先が未読なら関数を推測で作らず、読むためのボタンを表示する。読み込み後に候補を更新する。

対応するのは、JavaScript／TypeScriptの静的な相対importの名前付き・別名・名前空間と、名前のある単純なdefault export、Rustのcrateまたは同名クレートのuseの別名・グループ・self、Pythonの相対fromの別名・グループ・モジュール名。複数行の対応する宣言も記録する。外部パッケージや、探索ルートが不明なPythonの絶対importから、内部の関数を推測で対応づけない。拡張子を省略したPythonの参照を同名のJavaScriptファイルへ対応づけることも避ける。

引数の記述や簡単な局所宣言に同名があるときは、候補を示さず未解決とする。宣言の全体を解析していないため、この検査で全ての名前の衝突を検知するとは扱わない。入れ子の関数での呼び出しは、外側の関数の呼び出しとして重複させない。

呼び出し元は読取済みの最大400関数を探索し、最大80件を表示する。未読のコードの件数と探索・表示の上限を示す。候補がないことを呼び出しがない証明にしない。候補は読み込み宣言と名前に基づくもので、可視性・型・再代入・動的な束縛・実際の到達を完全に解決したものではない。再export、複雑な構文、ビルド設定、依存パッケージ内部は引き続き未対応。

読む順番は`ui/scanner.js`（読み込み名と参照先）、`ui/call-navigation.js`（候補と同名の記述）、`ui/comprehension.js`（関数の範囲・呼び出し元・探索上限）、`ui/explorer.js`（根拠と移動）。検証は`tools/call-navigation-tests.mjs`と`tools/explorer-smoke.mjs`。
